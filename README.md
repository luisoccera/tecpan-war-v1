# Técpan War - Primera Versión (Unreal Engine 5)

> 🎮 **"Muestra de la primera vez que toqué Unreal Engine"**

Este repositorio preserva de forma histórica el primer acercamiento al proyecto **Técpan War** en Unreal Engine 5.

## 📌 Contenido de esta versión inicial
- **Proyecto UE5**: TecpanWar.uproject y configuración base en Config/.
- **Assets de UE5**: Carpeta Content/ con los ~4,070 assets importados (House_0000.uasset a House_4060.uasset, materiales y texturas).
- **Modelo 3D Original**: 	ecpan_city.obj y 	ecpan_city.mtl (la primera versión generada con las casas individuales).
- **Vista previa**: preview_tecpan_war.jpg.
